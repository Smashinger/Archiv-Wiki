# Archiv Wiki

Ein persönliches Markdown-Wiki für den Desktop. Es organisiert Notizen in Haupt- und Unterkategorien mit einem Markdown-Editor, der direkt neben einer Live-Vorschau sitzt. Die App bietet Funktionen wie Editor mit Split-Ansicht, Callouts, Checklisten, interne Verlinkung, Code-Blöcke, Icon-Bibliothek, Rechtsklick-Menü, Zweigeteilte Suche, Startseite/Dashboard, zentrales Einstellungsfenster, Personalisierung, Cloud-Sync und automatisches lokales Backup. Es ist 100 % lokal und erfordert keine Cloud-Pflicht, Telemetrie oder Account.
