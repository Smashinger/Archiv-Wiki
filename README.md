# Archiv-Wiki ist umgezogen! 📦

![Archiv-Wiki-Banner](docs/branding/readme-banner-aw.png)

Die Weiterentwicklung, Fehlermeldungen (Issues) und alle künftigen Releases von **Archiv-Wiki** finden ab sofort auf **Codeberg** statt:

👉 **[https://codeberg.org/Smashii/Archiv-Wiki](https://codeberg.org/Smashii/Archiv-Wiki)**

---

### Was bedeutet das für bestehende Nutzer?

- **Automatische Updates:** Bestehende Installationen (ab Version 2.3.2) erhalten über dieses GitHub-Repository automatisch das Update auf **Version 2.4.0** (Brücken-Release).
- **Zukünftige Updates:** Ab Version 2.4.0 bezieht Archiv-Wiki alle neuen Aktualisierungen automatisch und direkt von Codeberg.
- **Neue Versionen & Downloads:** Die jeweils aktuellsten Releases und AppImages findest du ab sofort auf [Codeberg Releases](https://codeberg.org/Smashii/Archiv-Wiki/releases).
- **Fehler melden & mitwirken:** Bitte erstelle neue Tickets und Feature-Wünsche direkt im [Codeberg Issue-Tracker](https://codeberg.org/Smashii/Archiv-Wiki/issues).
